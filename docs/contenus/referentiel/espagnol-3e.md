## Chapitres et notions

| Lot        | Chapitre              | Notions                                                                        | État actuel                  |
| ---------- | --------------------- | ------------------------------------------------------------------------------ | ---------------------------- |
| `es-3e-01` | Le futur              | futur des réguliers ; irréguliers (tener, poner, hacer) ; emploi               | partielle (e3-futur)         |
| `es-3e-02` | Le passé composé      | haber + participe ; participes irréguliers ; passé composé ou passé simple     | partielle (e3-passe-compose) |
| `es-3e-03` | Le subjonctif présent | formation ; souhait et ordre ; défense (impératif négatif) ; emplois fréquents | absente                      |
| `es-3e-04` | Le groupe nominal     | diminutifs -ito, -illo ; faux-amis ; mots polysémiques ; lo + adjectif         | absente                      |
| `es-3e-05` | Subjonctif imparfait  | formation sur quelques verbes ; emploi dans l'hypothèse ; reconnaître          | absente                      |
| `es-3e-06` | Écouter et comprendre | document audio ; opinion ; repères culturels de 3e                             | absente                      |

États : **absente** (rien en ligne), **partielle** (chapitres existants à compléter et à porter à 5 niveaux),
**couverte** (5 niveaux, sources et relecture enregistrées).

Le nouveau programme de 3e s’applique à la rentrée 2028 ; d’ici là, le programme de 2020 reste celui du
brevet : chaque lot de 3e vérifie aussi qu’aucune notion du programme de 2020 n’est perdue.
