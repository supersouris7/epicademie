## Hors du jeu (non évaluable automatiquement)

Oral (prendre la parole, débattre), écriture longue (rédaction, réécriture), lecture d’œuvres intégrales,
démarches expérimentales et projets (sciences, technologie), pratique artistique : le jeu entraîne les
connaissances et les savoir-faire qui s’y rattachent (vocabulaire, règles, repères), sans prétendre les évaluer.
